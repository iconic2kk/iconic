Subject: 2027 verification calendar - tiers due before the owner mailing

The 2027 test calendar goes to plant owners on 20 October, so the tiers have to be reset under GV-STD-3 before then. EIA's
August 2026 monthly inventory (EIA-860M) is the latest release; the July release and the 2025 annual EIA-860 files are in the
shared folder too, along with the EIA-860 layout and instructions and the EIA-930 reference tables for the regional footprint.

Test crews: each verification test takes one crew-day on site plus a model review back at the desk. We have budget for 800
crew-days in 2027; if the calendar runs over that we will need to go back to the steering group, so please give the number
straight.

The scheduling system loads one row per unit. Owners get one letter per unit, so the unit list is what they will see.
