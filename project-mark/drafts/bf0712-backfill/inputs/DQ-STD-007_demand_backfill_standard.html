DQ-STD-007 Demand backfill standard

1. Purpose

The cleaned hourly demand series we publish is built from the demand values balancing authorities report on Form EIA-930. It has to describe the electricity load each BA actually served, hour by hour. This standard sets out when a reported demand value may be overwritten (backfilled) in the published series.

2. When a backfill is allowed

An hour may be backfilled only when the demand value the BA reported misstates the load the BA actually served in that hour.

The following are not grounds for a backfill, however far the value sits from expectations:

  • real changes in load, including weather, outages, storms, load shedding and restoration;
  • hours in which some other value, and not the reported demand, is the one in error.

3. How backfill jobs are decided

  • Backfill jobs are raised automatically from monitor incidents and list one row per incident.
  • The data owner decides each incident as a whole: every hour in an incident is either backfilled or left as reported.
  • An approved incident is backfilled exactly as the job specifies. The data owner can remove incidents from a job but cannot change the replacement values.
  • The data owner may run a job as submitted, run it with incidents removed, or reject it.
  • A decision must rest on evidence in the published EIA-930 data and EIA's documentation of it, and the reasoning is recorded for the governance board.
